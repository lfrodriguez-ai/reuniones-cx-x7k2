Validación API Genesys para Ops

12 de noviembre de 2026 · 12:00 (hora Colombia)
Participantes: Jaime Flautero, Monica Arias, Ricardo Andres Lopez Esquivel, Hugo Nelson Estupiñán García, Luis Felipe Rodríguez Martínez

Objetivo / tema principal

Validar la solicitud de API de Genesys (solo lectura) para un dashboard de alarmas en tiempo real para Operaciones, y definir quién lo construye y mantiene.

Principales temas tratados

  • Demo del dashboard en tiempo real con datos ficticios y bot de Slack
  • Alcance de la API: solo lectura, con segunda versión posible
  • Roadmap de Jaime: tiempo real vs histórico y paso a Adilabs
  • Capacidad de Datos/Intelligence (MAFE) y backlog de unas 40 tareas
  • Estado de Genesys en producción y onboarding

Resultado / resumen

Se avanza con una V1 de solo lectura como artefacto de Claude Code, con consultas cada 1 a 5 minutos. Operaciones será la fuente de verdad hasta que MAFE pueda asumirlo. Los permisos ya están resueltos; falta quién ejecute y mantenga.
